# Verificación del refactor a frontend, backend y JSON

- Dependencias de acceso a bases de datos y sus modelos decorados retirados; modelos de proyecto y mensaje definidos como interfaces.
- Configuración de contenedores, seed y herramientas de migración antiguas retirados del proyecto.
- Credenciales del panel conservadas y configuración privada depurada.
- Archivos reales `projects.json` y `messages.json` idénticos a sus copias previas al refactor.
- Exportación de 13 fichas y 59 archivos desde el JSON privado, sin iniciar la API.
- Backend y frontend compilan correctamente.
- 14 pruebas del backend, incluidas escrituras simultáneas, IDs, enlaces únicos, borradores y publicación de la copia estática.
- 3 pruebas de exportación, rutas seguras e inicialización que conserva datos privados existentes.
- `npm run check:api` inicia una API compilada con credenciales y carpetas temporales; verifica login válido e inválido, protección del panel, creación, subida de imagen, edición, publicación, persistencia tras reiniciar y borrado. Limpia sus archivos al terminar.

El editor necesita ejecutar el backend. El sitio público conserva su catálogo estático
y funciona con el backend apagado. En un alojamiento, los JSON y las subidas del
backend requieren almacenamiento persistente; publicar cambios estáticos requiere
volver a compilar y desplegar el frontend.
